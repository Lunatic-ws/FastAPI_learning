# 25 异步测试

## 概述

之前使用`TestClient`编写同步测试。但有时需要在测试中使用异步函数,例如异步查询数据库。

## pytest.mark.anyio

AnyIO提供了pytest插件,允许指定测试函数为异步。

## HTTPX

即使FastAPI应用使用`def`而非`async def`,底层仍是异步应用。

`TestClient`内部做了一些魔法来在同步测试函数中调用异步应用。但这在异步函数中不工作。

我们可以直接使用HTTPX来测试API。`TestClient`基于HTTPX构建。

## 示例

### 项目结构

```
.
├── app
│   ├── __init__.py
│   ├── main.py
│   └── test_main.py
```

### 应用代码

**main.py**:
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Tomato"}
```

### 测试代码

**test_main.py**:
```python
import pytest
from httpx import ASGITransport, AsyncClient
from .main import app

@pytest.mark.anyio
async def test_root():
    async with AsyncClient(
        transport=ASGITransport(app=app), base_url="http://test"
    ) as ac:
        response = await ac.get("/")
    assert response.status_code == 200
    assert response.json() == {"message": "Tomato"}
```

## 运行测试

```bash
uv run pytest
```

## 详解

### 异步测试标记

```python
@pytest.mark.anyio
async def test_root():
    # ...
```

`@pytest.mark.anyio`告诉pytest该测试函数应异步调用。

**注意**: 测试函数现在是`async def`而非`def`。

### AsyncClient

```python
async with AsyncClient(
    transport=ASGITransport(app=app), base_url="http://test"
) as ac:
    response = await ac.get("/")
```

创建`AsyncClient`并向其发送异步请求,使用`await`。

这等同于使用`TestClient`的:
```python
response = client.get('/')
```

**注意**: 使用AsyncClient时请求是异步的。

### Lifespan事件警告

如果应用依赖lifespan事件,`AsyncClient`不会触发这些事件。确保触发需使用[florimondmanca/asgi-lifespan](https://github.com/florimondmanca/asgi-lifespan#usage)的`LifespanManager`。

## 其他异步函数调用

由于测试函数是异步的,可以在测试中调用(并`await`)其他异步函数:

```python
import pytest
from httpx import ASGITransport, AsyncClient
from .main import app

async def some_async_function():
    # 模拟异步数据库查询
    await asyncio.sleep(0.1)
    return {"data": "value"}

@pytest.mark.anyio
async def test_with_async_operations():
    async with AsyncClient(
        transport=ASGITransport(app=app), base_url="http://test"
    ) as ac:
        response = await ac.get("/")
    
    # 调用其他异步函数
    data = await some_async_function()
    
    assert response.status_code == 200
    assert data["data"] == "value"
```

## 常见问题

### RuntimeError: Task attached to a different loop

当集成异步函数调用时(如使用MongoDB的MotorClient),可能遇到此错误。

解决方法: 在异步函数内实例化需要事件循环的对象,例如在`@app.on_event("startup")`回调中。

## 安装依赖

```bash
uv add pytest anyio httpx
```

## 小结

- 使用`@pytest.mark.anyio`标记异步测试函数
- 使用HTTPX的`AsyncClient`替代`TestClient`
- 测试函数中使用`async with`和`await`
- 可以在测试中调用其他异步函数
- 注意lifespan事件的处理
- 适用于测试异步数据库操作等场景
