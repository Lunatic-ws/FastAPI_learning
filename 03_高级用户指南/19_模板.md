# 19 模板

## 学习目标

- 掌握 Jinja2Templates 返回 HTML 页面
- 学会在模板中使用 `url_for` 和上下文变量

## 核心概念

### 1. 安装与基础用法

```bash
pip install jinja2
```

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates

app = FastAPI()

templates = Jinja2Templates(directory="templates")

@app.get("/items/{id}")
async def read_item(request: Request, id: int):
    return templates.TemplateResponse(
        request=request,
        name="item.html",
        context={"id": id},
    )
```

**模板文件 `templates/item.html`：**

```html
<html>
<body>
    <p>Item ID: {{ id }}</p>
    {% if items %}
    <ul>
    {% for item_url, item_name in items.items() %}
        <li><a href="{{ item_url }}">{{ item_name }}</a></li>
    {% endfor %}
    </ul>
    {% endif %}
</body>
</html>
```

- 必须在 context 中传 `request`（Jinja2 模板内部要用它处理 URL）
- 返回的响应 Content-Type 为 `text/html`

### 2. 在模板中生成接口地址：url_for

```python
@app.get("/items/{id}")
async def read_item(request: Request, id: int):
    return templates.TemplateResponse(
        request=request,
        name="item.html",
        context={
            "id": id,
            "items": {
                url_for("get_item", id=id): "Item by URL",
                "/items/42": "Item by path",
            },
        },
    )

@app.get("/items/{id}/link")
async def get_item(id: int):
    ...
```

- `url_for("函数名", **路径参数)` 在模板里生成正确的接口地址
- 模板中 `{{ url_for(...) }}` 也可直接用（因为 request 在 context 中）

### 3. 模板语法速查

| 语法 | 作用 |
|------|------|
| `{{ variable }}` | 输出变量（自动转义） |
| `{% if %}...{% endif %}` | 条件 |
| `{% for x in xs %}...{% endfor %}` | 循环 |
| `{% include "header.html" %}` | 引入子模板 |
| `{% extends "base.html" %}` + `{% block %}` | 模板继承 |

### 4. 模板 + 静态文件

HTML 页面通常引用 CSS/JS：

```html
<link href="{{ url_for('static', path='/styles.css') }}" rel="stylesheet">
```

配合 StaticFiles 挂载：

```python
from fastapi.staticfiles import StaticFiles
app.mount("/static", StaticFiles(directory="static"), name="static")
```

## 最佳实践

1. **模板放独立目录**：与代码分离，`templates/`、`static/` 各司其职
2. **用 url_for 而不是硬编码路径**：路径变更时模板不用改
3. **前后端一体的轻量应用才用模板**：重交互页面交给前端框架 + `app.frontend()` 或分离部署
4. **自动转义防 XSS**：Jinja2 默认对 `.html` 后缀模板开启自动转义，不要随意用 `| safe`

## 常见问题

**Q: TemplateResponse 报错找不到 request？**
A: 新版写法必须传 `request=request`，且 context 里通常也要包含

**Q: 和 StaticFiles 挂载有什么区别？**
A: StaticFiles 返回原样文件；模板是服务端渲染，按请求动态生成 HTML

**Q: 模板修改后不生效？**
A: Jinja2 有模板缓存，开发时重启服务或配置 `auto_reload=True`
