# 10 高级依赖注入

## 参数化依赖

所有之前看到的依赖都是固定的函数或类。但有时需要为依赖设置参数，而不必声明许多不同的函数或类。

### 可调用实例

Python中可以使类的实例成为"可调用"的（不仅是类本身，而是类的实例）。通过声明`__call__`方法实现：

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

class FixedContentQueryChecker:
    def __init__(self, fixed_content: str):
        self.fixed_content = fixed_content
    
    def __call__(self, q: str = ""):
        if q:
            return self.fixed_content in q
        return False

checker = FixedContentQueryChecker("bar")

@app.get("/query-checker/")
async def read_query_check(fixed_content_included: Annotated[bool, Depends(checker)]):
    return {"fixed_content_in_query": fixed_content_included}
```

- `__call__`是FastAPI用来检查额外参数和子依赖的方法
- `__init__`用于声明实例的参数，可以"参数化"依赖
- FastAPI不会触及`__init__`，只在代码中直接使用

### 创建和使用实例

```python
# 创建实例，参数化依赖
checker = FixedContentQueryChecker("bar")

# 使用实例作为依赖
# FastAPI会调用: checker(q="somequery")
@app.get("/query-checker/")
async def read_query_check(fixed_content_included: Annotated[bool, Depends(checker)]):
    return {"fixed_content_in_query": fixed_content_included}
```

## 依赖的yield、HTTPException、except和后台任务

### 带yield的依赖和scope

FastAPI 0.121.0版本添加了`Depends(scope="function")`支持：

- `Depends(scope="function")`：退出代码在路径操作函数完成后立即执行，在响应发送给客户端之前
- `Depends(scope="request")`（默认）：退出代码在响应发送后执行

### 带yield的依赖和StreamingResponse

在FastAPI 0.118.0之前，带`yield`的依赖退出代码会在路径操作函数返回后、发送响应前立即运行。

0.118.0版本恢复为：退出代码在响应发送后执行。

### 带yield的依赖和except

在FastAPI 0.110.0之前，如果依赖中使用`yield`后用`except`捕获异常且不再次抛出，异常会自动转发给异常处理器。

0.110.0版本改为：修复未处理异常的内存消耗问题，使其与常规Python代码行为一致。

### 后台任务与带yield的依赖

FastAPI 0.106.0之前，`yield`后的异常无法抛出，因为退出代码在响应发送后执行，异常处理器已经运行过。

**最佳实践**：后台任务应该有独立的资源（如自己的数据库连接），不应依赖带`yield`依赖的资源。

示例：
```python
# 错误做法：后台任务依赖已关闭的数据库会话
def get_session():
    with Session(engine) as session:
        yield session

def background_task(session: Session):  # 会话已关闭！
    pass

# 正确做法：后台任务内部创建自己的会话
def background_task(item_id: int):
    with Session(engine) as session:  # 新会话
        item = session.get(Item, item_id)
        # 处理逻辑
```
