# 26 设置与环境变量

## 概述

应用程序通常需要外部设置或配置,例如密钥、数据库凭证、邮件服务凭证等。这些设置通常是可变的,且很多是敏感信息,因此通常通过环境变量提供。

## 环境变量

环境变量是存在于操作系统中的值,可被应用程序和其他程序读取。

**注意**: 环境变量只能处理字符串,任何类型转换或验证都需要在代码中完成。

## Pydantic Settings

Pydantic提供了`pydantic-settings`包来处理来自环境变量的设置。

### 安装

```bash
uv add pydantic-settings
```

或安装FastAPI完整版:

```bash
uv add "fastapi[all]"
```

### 创建Settings对象

```python
from fastapi import FastAPI
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    app_name: str = "Awesome API"
    admin_email: str
    items_per_user: int = 50

settings = Settings()

app = FastAPI()

@app.get("/info")
async def info():
    return {
        "app_name": settings.app_name,
        "admin_email": settings.admin_email,
        "items_per_user": settings.items_per_user,
    }
```

Pydantic会以不区分大小写的方式读取环境变量,如`APP_NAME`会赋值给`app_name`属性。

### 运行服务器

Linux/macOS:
```bash
ADMIN_EMAIL="deadpool@example.com" APP_NAME="ChimichangApp" uv run fastapi run main.py
```

Windows PowerShell:
```powershell
$Env:ADMIN_EMAIL = "deadpool@example.com"
$Env:APP_NAME = "ChimichangApp"
uv run fastapi run main.py
```

## 在其他模块中使用

**config.py**:
```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    app_name: str = "Awesome API"
    admin_email: str
    items_per_user: int = 50

settings = Settings()
```

**main.py**:
```python
from fastapi import FastAPI
from .config import settings

app = FastAPI()

@app.get("/info")
async def info():
    return {
        "app_name": settings.app_name,
        "admin_email": settings.admin_email,
        "items_per_user": settings.items_per_user,
    }
```

## 在依赖中使用

使用依赖而非全局对象便于测试时覆盖。

**config.py**:
```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    app_name: str = "Awesome API"
    admin_email: str
    items_per_user: int = 50
```

**main.py**:
```python
from functools import lru_cache
from typing import Annotated
from fastapi import Depends, FastAPI
from .config import Settings

app = FastAPI()

@lru_cache
def get_settings():
    return Settings()

@app.get("/info")
async def info(settings: Annotated[Settings, Depends(get_settings)]):
    return {
        "app_name": settings.app_name,
        "admin_email": settings.admin_email,
        "items_per_user": settings.items_per_user,
    }
```

### 测试时覆盖

```python
from fastapi.testclient import TestClient
from .config import Settings
from .main import app, get_settings

client = TestClient(app)

def get_settings_override():
    return Settings(admin_email="testing_admin@example.com")

app.dependency_overrides[get_settings] = get_settings_override

def test_app():
    response = client.get("/info")
    data = response.json()
    assert data == {
        "app_name": "Awesome API",
        "admin_email": "testing_admin@example.com",
        "items_per_user": 50,
    }
```

## 从.env文件读取

环境变量可放在`.env`文件(dotenv)中:

**.env**:
```
ADMIN_EMAIL="deadpool@example.com"
APP_NAME="ChimichangApp"
```

### 配置Settings读取.env

```python
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    app_name: str = "Awesome API"
    admin_email: str
    items_per_user: int = 50

    model_config = SettingsConfigDict(env_file=".env")
```

需要安装`python-dotenv`:
```bash
uv add python-dotenv
```

## 使用lru_cache避免重复读取

读取文件是耗时操作,使用`@lru_cache`确保Settings对象只创建一次:

```python
from functools import lru_cache
from typing import Annotated
from fastapi import Depends, FastAPI
from . import config

app = FastAPI()

@lru_cache
def get_settings():
    return config.Settings()

@app.get("/info")
async def info(settings: Annotated[config.Settings, Depends(get_settings)]):
    return {
        "app_name": settings.app_name,
        "admin_email": settings.admin_email,
        "items_per_user": settings.items_per_user,
    }
```

### lru_cache工作原理

`@lru_cache`装饰器会缓存函数返回值,对相同参数的后续调用直接返回缓存值,不重新执行函数。

对于无参数的`get_settings()`,总是返回同一个Settings对象。

## 小结

- 使用Pydantic Settings管理配置,具有Pydantic模型的全部能力
- 通过依赖可简化测试
- 支持.env文件
- 使用`@lru_cache`避免重复读取.env文件,同时支持测试覆盖
- 环境变量命名不区分大小写
