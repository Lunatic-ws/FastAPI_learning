# 03 额外状态码 (Additional Status Codes)

## 概述

默认情况下，FastAPI会使用`JSONResponse`返回响应，并将你从路径操作中返回的内容放入该`JSONResponse`中。

它将使用默认状态码或你在路径操作中设置的状态码。

## 返回额外状态码

如果你想在主状态码之外返回其他状态码，可以通过直接返回`Response`（如`JSONResponse`）来实现，并直接设置额外状态码。

### 示例：更新或创建项目

假设你有一个路径操作允许更新项目，成功时返回HTTP状态码200 "OK"。

但同时你也希望它接受新项目。当项目之前不存在时，它创建项目并返回HTTP状态码201 "Created"。

```python
from typing import Annotated
from fastapi import Body, FastAPI, status
from fastapi.responses import JSONResponse

app = FastAPI()

items = {
    "foo": {"name": "Fighters", "size": 6},
    "bar": {"name": "Tenders", "size": 3}
}

@app.put("/items/{item_id}")
async def upsert_item(
    item_id: str,
    name: Annotated[str | None, Body()] = None,
    size: Annotated[int | None, Body()] = None,
):
    if item_id in items:
        item = items[item_id]
        item["name"] = name
        item["size"] = size
        return item
    else:
        item = {"name": name, "size": size}
        items[item_id] = item
        return JSONResponse(status_code=status.HTTP_201_CREATED, content=item)
```

### 重要提示

当你直接返回`Response`（如上例所示）时：
- 它将直接返回，不会被模型序列化等
- 确保它包含你想要的数据，且值是有效的JSON（如果使用`JSONResponse`）

### 技术细节

你也可以使用`from starlette.responses import JSONResponse`。

FastAPI提供了与`fastapi.responses`相同的`starlette.responses`，只是为了方便开发者。但大多数可用的响应直接来自Starlette。`status`也是一样。

## OpenAPI和API文档

如果你直接返回额外状态码和响应，它们不会包含在OpenAPI模式（API文档）中，因为FastAPI无法预先知道你要返回什么。

但你可以使用**额外响应**在代码中记录它。

## 关键点

1. **直接返回Response**：可以完全控制状态码和响应内容
2. **使用status模块**：使用`status.HTTP_201_CREATED`等常量更清晰
3. **文档缺失**：直接返回Response不会自动生成OpenAPI文档
4. **结合使用**：可以结合`responses`参数记录额外响应
