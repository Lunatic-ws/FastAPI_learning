# 07 查询参数模型

将相关的查询参数组织到一个 Pydantic 模型中，便于复用和统一验证。

## 核心概念

使用 Pydantic 模型声明查询参数组，然后用 `Query()` 声明参数，用 `Literal[]` 限制变量只能取特定的字面值：

```python
from typing import Annotated, Literal
from fastapi import FastAPI, Query
from pydantic import BaseModel, Field

app = FastAPI()

class FilterParams(BaseModel):
    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []

@app.get("/items/")
async def read_items(filter_query: Annotated[FilterParams, Query()]):
    return filter_query
```

FastAPI 会从查询参数中提取每个字段的数据。

## 禁止额外参数

使用 Pydantic 配置禁止额外字段：

```python
class FilterParams(BaseModel):
    model_config = {"extra": "forbid"}
    limit: int = Field(100, gt=0, le=100)
    # ...
```

如果客户端发送了未声明的查询参数，将收到错误响应。

## 要点

- Pydantic 模型用于声明一组相关的查询参数
- 支持验证、元数据、复用
- `model_config = {"extra": "forbid"}` 可限制只接收声明的参数
