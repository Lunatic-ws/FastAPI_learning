# 39 服务器发送事件（SSE）

使用Server-Sent Events流式传输数据，浏览器原生支持EventSource API。

## 安装

```bash
pip install fastapi uvicorn
```

## 什么是SSE？

Server-Sent Events是通过HTTP从服务器流式传输数据到客户端的标准。

每个事件是一个小文本块，包含`data`、`event`、`id`、`retry`等字段，用空行分隔。

示例：

```
data: {"name": "Portal Gun", "price": 999.99}
data: {"name": "Plumbus", "price": 32.99}
```

浏览器通过`EventSource` API原生支持SSE。

## 流式SSE示例

```python
from collections.abc import AsyncIterable
from fastapi import FastAPI
from fastapi.sse import EventSourceResponse
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None

items = [
    Item(name="Plumbus", description="A multi-purpose household device."),
    Item(name="Portal Gun", description="A portal opening device."),
    Item(name="Meeseeks Box", description="A box that summons a Meeseeks."),
]

@app.get("/items/stream", response_class=EventSourceResponse)
async def sse_items() -> AsyncIterable[Item]:
    for item in items:
        yield item
```

每个yield项编码为JSON，放入SSE事件的`data:`字段。

## ServerSentEvent对象

设置SSE字段（event、id、retry、comment）：

```python
from fastapi.sse import ServerSentEvent

@app.get("/items/stream", response_class=EventSourceResponse)
async def stream_items() -> AsyncIterable[ServerSentEvent]:
    yield ServerSentEvent(comment="stream of item updates")
    for i, item in enumerate(items):
        yield ServerSentEvent(
            data=item,
            event="item_update",
            id=str(i + 1),
            retry=5000
        )
```

## 原始数据

发送未经JSON编码的数据：

```python
@app.get("/logs/stream", response_class=EventSourceResponse)
async def stream_logs() -> AsyncIterable[ServerSentEvent]:
    logs = [
        "2025-01-01 INFO  Application started",
        "2025-01-01 DEBUG Connected to database",
        "2025-01-01 WARN  High memory usage detected",
    ]
    for log_line in logs:
        yield ServerSentEvent(raw_data=log_line)
```

`raw_data`发送预格式化文本，不进行JSON编码。

## 断点续传

浏览器重连时发送`Last-Event-ID`头：

```python
from typing import Annotated
from fastapi import Header

@app.get("/items/stream", response_class=EventSourceResponse)
async def stream_items(
    last_event_id: Annotated[int | None, Header()] = None,
) -> AsyncIterable[ServerSentEvent]:
    start = last_event_id + 1 if last_event_id is not None else 0
    for i, item in enumerate(items):
        if i < start:
            continue
        yield ServerSentEvent(data=item, id=str(i))
```

## SSE with POST

SSE支持任何HTTP方法：

```python
class Prompt(BaseModel):
    text: str

@app.post("/chat/stream", response_class=EventSourceResponse)
async def stream_chat(prompt: Prompt) -> AsyncIterable[ServerSentEvent]:
    words = prompt.text.split()
    for word in words:
        yield ServerSentEvent(data=word, event="token")
    yield ServerSentEvent(raw_data="[DONE]", event="done")
```

## 运行

```bash
uvicorn main:app --reload
```

## 访问

- http://127.0.0.1:8000/items/stream - SSE流式响应
- http://127.0.0.1:8000/docs - 自动文档

## 核心要点

- 导入`EventSourceResponse`和`ServerSentEvent`从`fastapi.sse`
- 设置`response_class=EventSourceResponse`
- `yield`生成SSE事件
- `ServerSentEvent`可设置event、id、retry、comment字段
- `data`字段自动JSON编码，`raw_data`发送原始文本
- 浏览器通过`EventSource` API原生支持
- 自动发送keep-alive ping（每15秒）
- 自动设置`Cache-Control: no-cache`和`X-Accel-Buffering: no`头
