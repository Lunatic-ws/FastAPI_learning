# 25 路径操作配置（Path Operation Configuration）

可以向路径操作装饰器传递多个参数来配置它。

**注意**：这些参数传递给**路径操作装饰器**，不是路径操作函数。

## 12.1 响应状态码

可以定义路径操作响应中使用的HTTP`status_code`。

可以直接传递`int`代码，如`404`。

如果不记得每个数字代码的含义，可以使用`status`中的快捷常量：

```python
from fastapi import FastAPI, status
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(item: Item) -> Item:
    return item
```

状态码将用于响应并添加到OpenAPI schema。

## 12.2 标签（Tags）

可以向路径操作添加标签，传递参数`tags`，值为`str`的`list`（通常只有一个`str`）：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()

@app.post("/items/", tags=["items"])
async def create_item(item: Item) -> Item:
    return item

@app.get("/items/", tags=["items"])
async def read_items():
    return [{"name": "Foo", "price": 42}]

@app.get("/users/", tags=["users"])
async def read_users():
    return [{"username": "johndoe"}]
```

标签会添加到OpenAPI schema，并被自动文档接口使用，在文档中分组显示路径操作。

### 使用枚举的标签

对于大型应用，可能需要确保相关路径操作使用相同的标签。可以将标签存储在`Enum`中：

```python
from enum import Enum
from fastapi import FastAPI

app = FastAPI()

class Tags(Enum):
    items = "items"
    users = "users"

@app.get("/items/", tags=[Tags.items])
async def get_items():
    return ["Portal gun", "Plumbus"]

@app.get("/users/", tags=[Tags.users])
async def read_users():
    return ["Rick", "Morty"]
```

## 12.3 摘要和描述

可以添加`summary`和`description`：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()

@app.post(
    "/items/",
    summary="Create an item",
    description="Create an item with all the information, name, description, price, tax and a set of unique tags",
)
async def create_item(item: Item) -> Item:
    return item
```

## 12.4 从文档字符串获取描述

描述通常很长且跨越多行，可以在函数的文档字符串中声明路径操作描述，FastAPI会从那里读取。

可以在文档字符串中写Markdown，它会被正确解释和显示：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()

@app.post("/items/", summary="Create an item")
async def create_item(item: Item) -> Item:
    """
    Create an item with all the information:

    - **name**: each item must have a name
    - **description**: a long description
    - **price**: required
    - **tax**: if the item doesn't have tax, you can omit this
    - **tags**: a set of unique tag strings for this item
    """
    return item
```

## 12.5 响应描述

可以用参数`response_description`指定响应描述：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()

@app.post(
    "/items/",
    summary="Create an item",
    response_description="The created item",
)
async def create_item(item: Item) -> Item:
    """
    Create an item with all the information:

    - **name**: each item must have a name
    - **description**: a long description
    - **price**: required
    - **tax**: if the item doesn't have tax, you can omit this
    - **tags**: a set of unique tag strings for this item
    """
    return item
```

**注意**：
- `response_description`专门指响应的描述
- `description`指路径操作的一般描述

**提示**：OpenAPI规定每个路径操作都需要响应描述。如果不提供，FastAPI会自动生成"Successful response"。

## 12.6 弃用路径操作

如果需要将路径操作标记为已弃用但不想删除，传递参数`deprecated=True`：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/", tags=["items"])
async def read_items():
    return [{"name": "Foo", "price": 42}]

@app.get("/users/", tags=["users"])
async def read_users():
    return [{"username": "johndoe"}]

@app.get("/elements/", tags=["items"], deprecated=True)
async def read_elements():
    return [{"item_id": "Foo"}]
```

在交互式文档中会清晰地标记为已弃用（带有删除线）。

## 小结

可以通过向路径操作装饰器传递参数轻松配置和添加路径操作的元数据：

- `status_code`：设置响应状态码
- `tags`：添加标签用于文档分组
- `summary`：简短摘要
- `description`：详细描述（可直接写在函数文档字符串）
- `response_description`：响应描述
- `deprecated`：标记为已弃用
