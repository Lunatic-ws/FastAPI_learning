# 42 前端

## 学习目标

- 掌握 `app.frontend()` 提供静态前端构建产物
- 理解 SPA 客户端路由的 fallback 机制
- 了解前端与 API 路由的优先级关系

## 核心概念

### 1. 场景说明

使用 Vite 的 React / Vue / Svelte / Angular / Astro / TanStack Router 等前端工具时，`npm run build` 会生成静态目录（如 `./dist/`）。`app.frontend()` 可以按前端框架的约定直接托管该目录，前后端同一个服务。

### 2. 提供前端服务

```python
from fastapi import FastAPI

app = FastAPI()

app.frontend("/", directory="dist")
```

项目结构：

```
.
├── pyproject.toml
├── app
│   ├── __init__.py
│   └── main.py
└── dist
    ├── index.html
    └── assets
        └── app.js
```

- 对 `/assets/app.js` 的请求会返回 `dist/assets/app.js`
- **API 优先**：FastAPI 先检查路径操作，只有没有普通路由匹配时才检查前端文件

### 3. 客户端路由（SPA fallback）

SPA 的路径如 `/dashboard/settings` 往往不是真实文件，而是由前端框架处理。浏览器直接访问该 URL 时，后端需要返回 `index.html`：

```python
app.frontend("/", directory="dist", fallback="index.html")
```

- 只有带 `Accept: text/html` 的 `GET`/`HEAD` 浏览器导航请求才使用 fallback
- 缺失的 JS / CSS / 图片等静态资源仍返回 `404`
- `POST` / `PUT` 等方法即使路径只匹配 fallback 也返回 `404`

### 4. 自定义 404 页面与自动 fallback

```python
# 缺失路径返回 404.html（保持 404 状态码）
app.frontend("/", directory="dist", fallback="404.html")

# 禁用 fallback，缺失路径一律普通 404
app.frontend("/", directory="dist", fallback=None)
```

默认 `fallback="auto"`：

- 存在 `404.html` → 缺失路径以 404 状态码返回它（适合 Astro 这类静态站点生成器）
- 否则存在 `index.html` → 缺失导航路径返回 `index.html`（适合 SPA）

所以大多数情况下只需写 `app.frontend("/", directory="dist")`。

### 5. 检查目录

默认 `check_dir="auto"`：

- 开发环境（`FASTAPI_ENV=development`，`fastapi dev` 会自动设置）：目录缺失只警告，允许先启动后端再构建前端
- 其他环境：应用创建时目录缺失直接报错，尽早发现配置问题

```python
# 前端由后续独立构建步骤生成时
app.frontend("/", directory="dist", check_dir=False)
```

### 6. 与 APIRouter 一起使用

```python
from fastapi import APIRouter, FastAPI

app = FastAPI()
router = APIRouter()

router.frontend("/", directory="dist", fallback="index.html")
app.include_router(router, prefix="/app")
```

前端会在 `/app` 路径下提供服务，所有常规路径操作（包括其他 router）仍优先。

### 7. 依赖项与中间件同样生效

前端响应运行在普通 FastAPI 应用内部：

- HTTP 中间件会应用于前端响应
- app、`APIRouter` 和 `include_router()` 的依赖项也会生效，可用于 cookie 认证等保护前端
- 依赖项也能像普通路径操作一样修改响应头、添加后台任务

## 最佳实践

1. **API 永远优先**：不必担心前端路径覆盖接口路由
2. **默认参数即可**：`fallback="auto"` + `check_dir="auto"` 覆盖绝大多数场景
3. **仅限静态构建输出**：`app.frontend()` 不做服务端渲染，不适用于 Next.js/Nuxt 等需要动态 SSR 的框架
4. **开发体验**：开发时先启动后端（`fastapi dev`），再另开终端跑前端构建，目录缺失不会报错

## 常见问题

**Q: 和 StaticFiles 挂载有什么区别？**
A: `app.frontend()` 专为前端框架约定设计：API 优先、自动处理 SPA fallback 和 404.html、支持 router 前缀，且不接管整个路径空间（`mount` 会吞掉前缀下所有请求）

**Q: 404 页面为什么状态码是 404？**
A: `fallback="404.html"` 时保持真实 404 状态码，对 SEO 和正确性都更友好

**Q: 浏览器直接刷新 SPA 子路径 404 了？**
A: 没开 fallback。使用 `app.frontend("/", directory="dist")` 即可，auto 模式会返回 index.html
