# 02 路径参数

使用路径参数声明动态路径。

## 基本用法

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

访问 `/items/5` 返回 `{"item_id": 5}`

## 类型转换

FastAPI 根据类型注解自动转换和验证：

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

- 访问 `/items/3` → item_id = 3 (int)
- 访问 `/items/foo` → 返回 422 错误（不是有效整数）

## 路径顺序

更具体的路径应放在前面：

```python
@app.get("/users/me")
async def read_users_me():
    return {"user_id": "current user"}

@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```

如果顺序反了，`/users/me` 会被当作 `user_id="me"` 处理。

## 枚举路径参数

使用 Enum 限制可选值：

```python
from enum import Enum

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model": model_name, "message": "Deep Learning FTW!"}
    return {"model": model_name}
```

## 路径参数包含路径

使用 `Path` 类型让参数包含路径：

```python
from fastapi import Path

@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

访问 `/files/home/johndoe/myfile.txt` → `file_path = "home/johndoe/myfile.txt"`

## 要点

- `{param}` 声明路径参数
- 类型注解用于转换和验证
- 路径顺序很重要（具体在前）
- Enum 限制可选值
- `:path` 声明包含路径的参数
