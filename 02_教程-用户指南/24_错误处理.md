# 24 错误处理（Handling Errors）

在API开发中，需要向客户端报告错误是很常见的。客户端可能是浏览器前端、其他人的代码、IoT设备等。

需要告诉客户端的情况包括：
- 客户端没有足够的权限执行操作
- 客户端没有访问该资源的权限
- 客户端尝试访问的项目不存在
- 等等

在这些情况下，通常会返回**400-499范围内**的HTTP状态码，这表示客户端发生了错误。

## 11.1 使用 HTTPException

要向客户端返回错误响应，使用`HTTPException`。

### 导入 HTTPException

```python
from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}

@app.get("/items/{item_id}")
async def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"item": items[item_id]}
```

### 抛出 HTTPException

`HTTPException`是一个普通的Python异常，带有与API相关的额外数据。

因为是Python异常，不要`return`它，要`raise`它。

这意味着如果在路径操作函数内调用的工具函数中抛出`HTTPException`，它不会执行路径操作函数中的其余代码，会立即终止请求并将HTTP错误发送给客户端。

### 结果响应

- 客户端请求`http://example.com/items/foo`（存在的`item_id`）
  - 返回HTTP状态码200
  - JSON响应：`{"item": "The Foo Wrestlers"}`

- 客户端请求`http://example.com/items/bar`（不存在的`item_id`）
  - 返回HTTP状态码404
  - JSON响应：`{"detail": "Item not found"}`

**提示**：`detail`参数可以传递任何可转换为JSON的值，不只是`str`，可以是`dict`、`list`等。

## 11.2 添加自定义头部

在某些情况下，能够向HTTP错误添加自定义头部很有用，例如某些安全场景。

```python
from fastapi import FastAPI, HTTPException

app = FastAPI()

items = {"foo": "The Foo Wrestlers"}

@app.get("/items-header/{item_id}")
async def read_item_header(item_id: str):
    if item_id not in items:
        raise HTTPException(
            status_code=404,
            detail="Item not found",
            headers={"X-Error": "There goes my error"},
        )
    return {"item": items[item_id]}
```

## 11.3 安装自定义异常处理器

可以使用Starlette的异常工具添加自定义异常处理器。

假设有一个自定义异常`UnicornException`，希望全局处理这个异常。

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

class UnicornException(Exception):
    def __init__(self, name: str):
        self.name = name

app = FastAPI()

@app.exception_handler(UnicornException)
async def unicorn_exception_handler(request: Request, exc: UnicornException):
    return JSONResponse(
        status_code=418,
        content={"message": f"Oops! {exc.name} did something. There goes a rainbow..."},
    )

@app.get("/unicorns/{name}")
async def read_unicorn(name: str):
    if name == "yolo":
        raise UnicornException(name=name)
    return {"unicorn_name": name}
```

如果请求`/unicorns/yolo`，将抛出`UnicornException`，但会被`unicorn_exception_handler`处理，返回HTTP状态码418和JSON内容。

## 11.4 覆盖默认异常处理器

FastAPI有一些默认异常处理器，负责在抛出`HTTPException`和请求包含无效数据时返回默认JSON响应。

可以覆盖这些异常处理器。

### 覆盖请求验证异常

当请求包含无效数据时，FastAPI内部抛出`RequestValidationError`。

要覆盖它，导入`RequestValidationError`并使用`@app.exception_handler(RequestValidationError)`装饰异常处理器。

```python
from fastapi import FastAPI, HTTPException
from fastapi.exceptions import RequestValidationError
from fastapi.responses import PlainTextResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()

@app.exception_handler(StarletteHTTPException)
async def http_exception_handler(request, exc):
    return PlainTextResponse(str(exc.detail), status_code=exc.status_code)

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc: RequestValidationError):
    message = "Validation errors:"
    for error in exc.errors():
        message += f"\nField: {error['loc']}, Error: {error['msg']}"
    return PlainTextResponse(message, status_code=400)

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 3:
        raise HTTPException(status_code=418, detail="Nope! I don't like 3.")
    return {"item_id": item_id}
```

现在访问`/items/foo`，会得到文本版本的验证错误，而不是默认的JSON错误。

### 使用 RequestValidationError 的 body

`RequestValidationError`包含接收到的无效数据的`body`，可以在开发时用于记录和调试。

```python
from fastapi import FastAPI, Request
from fastapi.encoders import jsonable_encoder
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from pydantic import BaseModel

app = FastAPI()

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    return JSONResponse(
        status_code=422,
        content=jsonable_encoder({"detail": exc.errors(), "body": exc.body}),
    )

class Item(BaseModel):
    title: str
    size: int

@app.post("/items/")
async def create_item(item: Item):
    return item
```

发送无效项目：
```json
{
  "title": "towel",
  "size": "XL"
}
```

会收到包含接收到的body的错误响应：
```json
{
  "detail": [
    {
      "loc": ["body", "size"],
      "msg": "value is not a valid integer",
      "type": "type_error.integer"
    }
  ],
  "body": {
    "title": "towel",
    "size": "XL"
  }
}
```

### FastAPI的 HTTPException vs Starlette的 HTTPException

FastAPI有自己的`HTTPException`，继承自Starlette的`HTTPException`。

区别：FastAPI的`HTTPException`接受任何JSON可序列化数据作为`detail`字段，而Starlette的只接受字符串。

注册异常处理器时，应该注册Starlette的`HTTPException`，这样Starlette内部代码或扩展抛出的异常也能被处理。

重命名导入：
```python
from starlette.exceptions import HTTPException as StarletteHTTPException
```

### 复用FastAPI的异常处理器

如果想使用异常同时保持FastAPI的默认异常处理器，可以导入并复用：

```python
from fastapi import FastAPI, HTTPException
from fastapi.exception_handlers import (
    http_exception_handler,
    request_validation_exception_handler,
)
from fastapi.exceptions import RequestValidationError
from starlette.exceptions import HTTPException as StarletteHTTPException

app = FastAPI()

@app.exception_handler(StarletteHTTPException)
async def custom_http_exception_handler(request, exc):
    print(f"OMG! An HTTP error!: {repr(exc)}")
    return await http_exception_handler(request, exc)

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc):
    print(f"OMG! The client sent invalid data!: {exc}")
    return await request_validation_exception_handler(request, exc)

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 3:
        raise HTTPException(status_code=418, detail="Nope! I don't like 3.")
    return {"item_id": item_id}
```

## 小结

- 使用`HTTPException`向客户端返回HTTP错误响应
- 可以添加自定义头部到错误响应
- 可以安装自定义异常处理器处理自定义异常
- 可以覆盖FastAPI的默认异常处理器
- `RequestValidationError`包含验证错误详情和原始请求body
- 注册异常处理器时使用Starlette的`HTTPException`以捕获所有HTTP异常
