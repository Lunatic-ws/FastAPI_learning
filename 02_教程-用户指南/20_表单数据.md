# 20 表单数据（Form Data）

## 概念解释

表单数据是Web应用中常用的数据提交方式，与JSON数据不同，表单数据使用 `application/x-www-form-urlencoded` 或 `multipart/form-data` 编码类型。

FastAPI提供了 `Form()` 函数来声明表单参数，类似于 `Body()` 用于JSON数据。

## 核心概念

### 1. Form() 函数

用于声明表单字段参数，自动从表单数据中提取值。

```python
from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/login/")
async def login(username: str = Form(), password: str = Form()):
    return {"username": username}
```

### 2. 表单数据编码

- **application/x-www-form-urlencoded**：默认编码方式，用于普通表单字段
- **multipart/form-data**：用于文件上传或混合表单数据

### 3. 表单字段类型

```python
from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/submit/")
async def submit(
    name: str = Form(),
    age: int = Form(),
    email: str = Form(default=""),
    is_active: bool = Form(default=True)
):
    return {
        "name": name,
        "age": age,
        "email": email,
        "is_active": is_active
    }
```

### 4. 表单数据验证

```python
from fastapi import FastAPI, Form
from pydantic import constr

app = FastAPI()

@app.post("/register/")
async def register(
    username: constr(min_length=3, max_length=20) = Form(),
    password: constr(min_length=6) = Form()
):
    return {"username": username, "status": "registered"}
```

### 5. 可选表单字段

```python
from fastapi import FastAPI, Form
from typing import Optional

app = FastAPI()

@app.post("/update-profile/")
async def update_profile(
    name: str = Form(),
    nickname: Optional[str] = Form(default=None),
    bio: Optional[str] = Form(default="")
):
    return {
        "name": name,
        "nickname": nickname,
        "bio": bio
    }
```

## 代码示例

### 示例1：用户登录

```python
from fastapi import FastAPI, Form
from fastapi.responses import JSONResponse

app = FastAPI()

@app.post("/login")
async def login(
    username: str = Form(),
    password: str = Form()
):
    # 验证逻辑（示例）
    if username == "admin" and password == "secret":
        return {"status": "success", "message": "登录成功"}
    return JSONResponse(
        status_code=401,
        content={"status": "error", "message": "用户名或密码错误"}
    )
```

### 示例2：用户注册表单

```python
from fastapi import FastAPI, Form
from typing import Optional

app = FastAPI()

@app.post("/register")
async def register(
    username: str = Form(min_length=3),
    email: str = Form(),
    password: str = Form(min_length=6),
    confirm_password: str = Form(),
    phone: Optional[str] = Form(default=None)
):
    if password != confirm_password:
        return {"error": "两次密码不一致"}
    
    return {
        "username": username,
        "email": email,
        "phone": phone,
        "status": "registered"
    }
```

### 示例3：表单数据与文件混合

```python
from fastapi import FastAPI, Form, File, UploadFile

app = FastAPI()

@app.post("/submit-with-file/")
async def submit_with_file(
    name: str = Form(),
    description: str = Form(),
    file: UploadFile = File()
):
    content = await file.read()
    return {
        "name": name,
        "description": description,
        "filename": file.filename,
        "size": len(content)
    }
```

## 关键要点

1. **使用Form()而非Body()**：接收表单数据时必须使用 `Form()`，不能使用 `Body()` 或直接声明参数

2. **表单字段必须显式声明**：每个表单字段都需要用 `Form()` 声明，不能省略

3. **表单数据的HTML示例**：
   ```html
   <form action="/login/" method="post">
       <input type="text" name="username">
       <input type="password" name="password">
       <input type="submit">
   </form>
   ```

4. **测试表单接口**：使用 `curl` 或 `requests` 测试
   ```bash
   curl -X POST "http://localhost:8000/login/" \
        -H "Content-Type: application/x-www-form-urlencoded" \
        -d "username=john&password=secret"
   ```

5. **与JSON的区别**：
   - 表单数据：`Content-Type: application/x-www-form-urlencoded`
   - JSON数据：`Content-Type: application/json`

6. **默认值与可选字段**：使用 `Form(default=...)` 或 `Form(default=None)` 设置默认值

7. **验证规则**：Form() 支持所有 Pydantic 验证功能，如 `min_length`、`max_length` 等

8. **OpenAPI文档**：FastAPI自动在Swagger UI中生成表单输入框
