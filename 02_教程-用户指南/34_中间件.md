# 34 中间件（Middleware）

可以为FastAPI应用添加中间件。

"中间件"是一个函数，在每个**请求**被任何特定路径操作处理之前工作，也在每个**响应**返回之前工作。

- 接收到应用的每个**请求**
- 可以对该**请求**做些什么或运行任何需要的代码
- 然后将**请求**传递给应用的其余部分处理（通过某个路径操作）
- 然后获取应用（通过某个路径操作）生成的**响应**
- 可以对该**响应**做些什么或运行任何需要的代码
- 然后返回**响应**

**技术细节**：
- 如果有使用`yield`的依赖，退出代码将在中间件**之后**运行
- 如果有后台任务，它们将在所有中间件**之后**运行

## 13.1 创建中间件

使用装饰器`@app.middleware("http")`创建中间件。

中间件函数接收：
- `request`：请求对象
- `call_next`：一个函数，接收`request`作为参数
  - 这个函数会将`request`传递给相应的路径操作
  - 然后返回相应路径操作生成的`response`

示例：添加处理时间头部

```python
import time
from fastapi import FastAPI, Request

app = FastAPI()

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start_time = time.perf_counter()
    response = await call_next(request)
    process_time = time.perf_counter() - start_time
    response.headers["X-Process-Time"] = str(process_time)
    return response
```

这个中间件：
1. 在处理请求前记录开始时间
2. 调用`call_next(request)`处理请求并获取响应
3. 计算处理时间
4. 添加自定义头部`X-Process-Time`
5. 返回修改后的响应

**提示**：
- 自定义专有头部可以使用`X-`前缀
- 如果希望浏览器客户端能看到自定义头部，需要在CORS配置中使用`expose_headers`参数

### 在响应前后执行代码

可以在任何路径操作接收请求**之前**添加代码，也可以在生成响应**之后**、返回之前添加代码。

```python
import time
from fastapi import FastAPI, Request

app = FastAPI()

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    # 请求前
    start_time = time.perf_counter()
    
    # 处理请求
    response = await call_next(request)
    
    # 响应后
    process_time = time.perf_counter() - start_time
    response.headers["X-Process-Time"] = str(process_time)
    
    return response
```

## 13.2 多个中间件的执行顺序

使用`@app.middleware()`装饰器或`app.add_middleware()`方法添加多个中间件时，每个新中间件包装应用，形成一个栈。

最后添加的中间件是**最外层**，第一个添加的是**最内层**。

**请求路径**：最外层中间件先执行
**响应路径**：最后执行

示例：
```python
app.add_middleware(MiddlewareA)
app.add_middleware(MiddlewareB)
```

执行顺序：
- **请求**：MiddlewareB → MiddlewareA → route
- **响应**：route → MiddlewareA → MiddlewareB

这种栈行为确保中间件以可预测和可控的顺序执行。

## 小结

- 中间件在每个请求处理前和响应返回前执行
- 使用`@app.middleware("http")`装饰器创建中间件
- 中间件接收`request`和`call_next`参数
- 调用`call_next(request)`处理请求并获取响应
- 可以在响应前后执行代码
- 多个中间件形成栈结构，执行顺序可预测
