# 43 静态文件（Static Files）

## 核心概念

使用`StaticFiles`可以自动从目录提供静态文件服务。

### 基本用法

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

app.mount("/static", StaticFiles(directory="static"), name="static")
```

### 什么是"挂载"（Mounting）

"挂载"意味着在特定路径添加一个完整的"独立"应用，该应用负责处理所有子路径。

**与APIRouter的区别**：
- 挂载的应用完全独立
- 主应用的OpenAPI和文档不会包含挂载应用的内容
- 挂载应用有自己的路由系统

### 参数说明

```python
app.mount("/static", StaticFiles(directory="static"), name="static")
```

- `"/static"`：挂载的子路径，所有以此开头的URL都由`StaticFiles`处理
- `directory="static"`：包含静态文件的目录名
- `name="static"`：内部使用的名称（用于反向URL生成）

## 使用示例

### 目录结构

```
.
├── main.py
└── static/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    └── images/
        └── logo.png
```

### 代码实现

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# 挂载静态文件目录
app.mount("/static", StaticFiles(directory="static"), name="static")

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

### 访问静态文件

```
GET /static/css/style.css
GET /static/js/script.js
GET /static/images/logo.png
```

## 高级用法

### 多个静态文件目录

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# 挂载多个静态文件目录
app.mount("/static", StaticFiles(directory="static"), name="static")
app.mount("/uploads", StaticFiles(directory="uploads"), name="uploads")
app.mount("/assets", StaticFiles(directory="assets"), name="assets")
```

### 嵌套挂载

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# 在不同路径挂载
app.mount("/v1/static", StaticFiles(directory="static_v1"), name="static_v1")
app.mount("/v2/static", StaticFiles(directory="static_v2"), name="static_v2")
```

## 实际应用场景

### 1. 提供前端静态资源

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# API路由
@app.get("/api/items")
async def get_items():
    return {"items": []}

# 静态文件（CSS、JS、图片等）
app.mount("/static", StaticFiles(directory="frontend/static"), name="static")
```

### 2. 用户上传文件服务

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# 用户上传的文件
app.mount("/uploads", StaticFiles(directory="user_uploads"), name="uploads")

@app.post("/api/upload")
async def upload_file():
    # 处理文件上传
    pass
```

### 3. 版本化静态资源

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# 不同版本的静态资源
app.mount("/v1/assets", StaticFiles(directory="assets_v1"), name="assets_v1")
app.mount("/v2/assets", StaticFiles(directory="assets_v2"), name="assets_v2")
```

## 注意事项

1. **目录必须存在**：指定的目录必须存在，否则会报错
2. **自动索引**：默认情况下，访问目录路径会返回404，不会列出文件列表
3. **缓存控制**：生产环境建议配置CDN或Nginx处理静态文件
4. **安全考虑**：确保不暴露敏感文件（如配置文件、密钥等）

## 性能优化建议

### 开发环境 vs 生产环境

**开发环境**：使用`StaticFiles`即可

**生产环境**：推荐使用专业的Web服务器
- Nginx
- Apache
- CDN服务

```python
import os
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

# 仅在开发环境挂载静态文件
if os.getenv("ENV") == "development":
    app.mount("/static", StaticFiles(directory="static"), name="static")
```

## 关键要点

1. **简单易用**：一行代码即可提供静态文件服务
2. **挂载机制**：理解挂载与路由的区别
3. **路径映射**：URL路径与文件系统目录的对应关系
4. **生产部署**：生产环境使用专业服务器或CDN

## 前端托管替代方案

如果需要托管前端应用，推荐使用`app.frontend()`（FastAPI 0.100.0+）：

```python
from fastapi import FastAPI

app = FastAPI()

# 自动处理前端静态文件和客户端路由
# app.frontend(root_path="frontend")
```

`app.frontend()`内部使用`StaticFiles`，并额外支持：
- 客户端路由处理（SPA）
- 自动检测前端构建目录
