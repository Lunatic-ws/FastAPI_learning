# 23 表单与文件 (Request Forms and Files)

## 学习目标

学习如何在同一个请求中同时定义文件和表单字段。

## 前置要求

要接收上传的文件和/或表单数据，首先需要安装 `python-multipart`：

```bash
pip install python-multipart
```

## 导入 File 和 Form

```python
from typing import Annotated
from fastapi import FastAPI, File, Form, UploadFile

app = FastAPI()


@app.post("/files/")
async def create_file(
    file: Annotated[bytes, File()],
    fileb: Annotated[UploadFile, File()],
    token: Annotated[str, Form()],
):
    return {
        "file_size": len(file),
        "token": token,
        "fileb_content_type": fileb.content_type,
    }
```

## 定义 File 和 Form 参数

创建文件和表单参数的方式与 `Body` 或 `Query` 相同：

```python
from typing import Annotated
from fastapi import FastAPI, File, Form, UploadFile

app = FastAPI()


@app.post("/files/")
async def create_file(
    file: Annotated[bytes, File()],
    fileb: Annotated[UploadFile, File()],
    token: Annotated[str, Form()],
):
    return {
        "file_size": len(file),
        "token": token,
        "fileb_content_type": fileb.content_type,
    }
```

文件和表单字段将作为表单数据上传，你将接收到文件和表单字段。

你可以将一些文件声明为 `bytes`，另一些声明为 `UploadFile`。

## 重要限制

**警告**：你可以在一个路径操作中声明多个 `File` 和 `Form` 参数，但不能同时声明期望作为 JSON 接收的 `Body` 字段，因为请求将使用 `multipart/form-data` 而不是 `application/json` 编码正文。

这不是 FastAPI 的限制，而是 HTTP 协议的一部分。

## 代码示例

### 完整示例

```python
from typing import Annotated
from fastapi import FastAPI, File, Form, UploadFile

app = FastAPI()


@app.post("/upload/")
async def upload_file_and_data(
    file: Annotated[UploadFile, File(description="上传的文件")],
    description: Annotated[str, Form(description="文件描述")],
    category: Annotated[str, Form(description="文件分类")],
):
    return {
        "filename": file.filename,
        "content_type": file.content_type,
        "description": description,
        "category": category,
    }
```

### 多文件上传示例

```python
from typing import Annotated, List
from fastapi import FastAPI, File, Form, UploadFile

app = FastAPI()


@app.post("/upload-multiple/")
async def upload_multiple_files(
    files: Annotated[List[UploadFile], File(description="多个上传文件")],
    description: Annotated[str, Form(description="描述")],
):
    return {
        "file_count": len(files),
        "filenames": [file.filename for file in files],
        "description": description,
    }
```

## 核心要点

1. 可以同时使用 `File` 和 `Form` 接收数据和文件
2. 文件可以声明为 `bytes` 或 `UploadFile`
3. 不能同时使用 JSON body 和文件/表单数据
4. 请求必须使用 `multipart/form-data` 编码
5. 需要 `python-multipart` 依赖

## 实际应用场景

- 上传文件并附带描述信息
- 提交包含文件的表单
- 头像上传（文件 + 用户信息）
- 文档上传（文件 + 分类、标签等）
