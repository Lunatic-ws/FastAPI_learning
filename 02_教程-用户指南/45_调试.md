# 45 调试

FastAPI应用可以直接从代码中调用uvicorn运行，这样可以使用调试器（如VS Code或PyCharm的调试器）进行调试。

## 直接调用Uvicorn

在FastAPI应用中直接导入并运行uvicorn：

```python
import uvicorn
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    a = "a"
    b = "b" + a
    return {"hello world": b}

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 关于 `__name__ == "__main__"`

这个条件判断的目的是：

- 当直接运行文件时（`python myapp.py`），`__name__`的值是`"__main__"`，会执行uvicorn.run()
- 当文件被导入时（`from myapp import app`），`__name__`的值不是`"__main__"`，不会执行uvicorn.run()

这样可以避免在导入模块时自动启动服务器。

## 使用调试器

### VS Code调试

1. 打开"Run and Debug"面板
2. 点击"Add configuration..."
3. 选择"Python"
4. 运行调试器选择"Python: Current File"

调试器会启动服务器并在断点处停止。

### PyCharm调试

1. 打开"Run"菜单
2. 选择"Debug..."
3. 选择要调试的文件

调试器会启动服务器并在断点处停止。
