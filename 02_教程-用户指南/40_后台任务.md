# 40 后台任务（Background Tasks）

可以定义后台任务在返回响应**之后**运行。

适用于请求后需要执行但客户端不必等待的操作。

## 16.1 使用场景

- **发送邮件通知**：连接邮件服务器并发送邮件需要几秒，可以立即返回响应，后台发送邮件
- **处理数据**：接收文件需要慢速处理，可以返回"Accepted"（HTTP 202），后台处理文件

## 16.2 使用BackgroundTasks

导入`BackgroundTasks`并在路径操作函数中声明参数：

```python
from fastapi import BackgroundTasks, FastAPI

app = FastAPI()

def write_notification(email: str, message=""):
    with open("log.txt", mode="w") as email_file:
        content = f"notification for {email}: {message}"
        email_file.write(content)

@app.post("/send-notification/{email}")
async def send_notification(email: str, background_tasks: BackgroundTasks):
    background_tasks.add_task(write_notification, email, message="some notification")
    return {"message": "Notification sent in the background"}
```

FastAPI会创建`BackgroundTasks`对象并作为参数传递。

## 16.3 创建任务函数

任务函数是标准函数，可以接收参数：

- 可以是`async def`或普通`def`
- FastAPI会正确处理

示例中，任务函数写入文件（模拟发送邮件）：

```python
def write_notification(email: str, message=""):
    with open("log.txt", mode="w") as email_file:
        content = f"notification for {email}: {message}"
        email_file.write(content)
```

因为写操作不使用`async`和`await`，所以使用普通`def`。

## 16.4 添加后台任务

在路径操作函数中，使用`.add_task()`方法添加任务：

```python
background_tasks.add_task(write_notification, email, message="some notification")
```

`.add_task()`参数：
1. 任务函数（`write_notification`）
2. 按顺序传递的位置参数（`email`）
3. 关键字参数（`message="some notification"`）

## 16.5 依赖注入中使用

`BackgroundTasks`也适用于依赖注入系统：

```python
from typing import Annotated
from fastapi import BackgroundTasks, Depends, FastAPI

app = FastAPI()

def write_log(message: str):
    with open("log.txt", mode="a") as log:
        log.write(message)

def get_query(background_tasks: BackgroundTasks, q: str | None = None):
    if q:
        message = f"found query: {q}\n"
        background_tasks.add_task(write_log, message)
    return q

@app.post("/send-notification/{email}")
async def send_notification(
    email: str, background_tasks: BackgroundTasks, q: Annotated[str, Depends(get_query)]
):
    message = f"message to {email}\n"
    background_tasks.add_task(write_log, message)
    return {"message": "Message sent"}
```

可以在多个层级声明`BackgroundTasks`：
- 路径操作函数
- 依赖（可依赖项）
- 子依赖

FastAPI会合并所有后台任务并在响应后运行。

## 16.6 技术细节

`BackgroundTasks`类来自`starlette.background`。

FastAPI导入它以避免与`BackgroundTask`（单数形式）混淆。

使用`BackgroundTasks`（复数）可以让FastAPI处理创建对象等工作。

## 16.7 使用场景选择

### BackgroundTasks适用场景
- 需要访问同一FastAPI应用的变量和对象
- 执行小型后台任务（如发送邮件通知）
- 不需要跨进程或服务器

### Celery适用场景
- 需要执行繁重的后台计算
- 不需要在同一进程运行
- 不需要共享内存、变量等
- 需要在多进程或多服务器运行

Celery需要更复杂的配置和消息队列（RabbitMQ、Redis），但更强大。

## 小结

- 后台任务在返回响应后运行
- 使用`BackgroundTasks`参数声明
- 任务函数可以是`async def`或`def`
- 使用`.add_task()`添加任务
- 支持依赖注入系统
- 适用于小型任务、共享内存场景
- 大型任务考虑使用Celery
