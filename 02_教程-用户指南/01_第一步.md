# 第一步

创建一个最基本的 FastAPI 应用。

## 安装

```bash
pip install fastapi uvicorn
```

## 最简应用

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

## 运行

```bash
uvicorn main:app --reload
```

- `main`: 文件名（main.py）
- `app`: 应用对象名
- `--reload`: 开发模式自动重载

## 访问

- http://127.0.0.1:8000/ - API 返回 {"message": "Hello World"}
- http://127.0.0.1:8000/docs - 自动生成的交互式文档（Swagger UI）
- http://127.0.0.1:8000/redoc - 备用文档（ReDoc）

## 核心要点

- `FastAPI()` 创建应用实例
- `@app.get("/")` 声明路径操作（装饰器）
- `async def` 定义路径操作函数
- `return` 返回值自动转换为 JSON
- 自动生成 OpenAPI 文档
