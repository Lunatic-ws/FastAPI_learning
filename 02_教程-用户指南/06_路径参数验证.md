# 06 - 路径参数验证 (Path Parameters and Numeric Validations)

## 学习目标

掌握如何使用 `Path` 为路径参数添加验证和元数据，特别是数值验证。

---

## 核心概念

路径参数和查询参数一样，可以使用 `Path` 添加验证和元数据。

**重要**：路径参数总是必需的，即使声明了默认值也无效。

---

## 导入 Path

```python
from typing import Annotated
from fastapi import FastAPI, Path

app = FastAPI()
```

---

## 声明元数据

```python
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(title="The ID of the item to get")]
):
    return {"item_id": item_id}
```

`Path` 支持 `Query` 的所有参数：
- `title`
- `description`
- `alias`
- `deprecated`
- 等等

---

## 数值验证

### 1. ge (greater than or equal) - 大于等于

```python
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(ge=1)]
):
    # item_id 必须大于等于 1
    return {"item_id": item_id}
```

**测试**：
- ✅ `/items/1` - 有效
- ✅ `/items/100` - 有效
- ❌ `/items/0` - 无效
- ❌ `/items/-5` - 无效

### 2. gt (greater than) - 大于

```python
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(gt=0)]
):
    # item_id 必须大于 0
    return {"item_id": item_id}
```

### 3. le (less than or equal) - 小于等于

```python
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(le=1000)]
):
    # item_id 必须小于等于 1000
    return {"item_id": item_id}
```

### 4. lt (less than) - 小于

```python
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(lt=100)]
):
    # item_id 必须小于 100
    return {"item_id": item_id}
```

## 组合验证

### 示例：范围验证

```python
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(gt=0, le=1000)]
):
    # item_id 必须：大于 0 且 小于等于 1000
    # 有效范围：1 - 1000
    return {"item_id": item_id}
```

### 示例：浮点数验证

```python
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(ge=0, le=1000)],
    size: Annotated[float, Query(gt=0, lt=10.5)]
):
    # size 是浮点数：大于 0，小于 10.5
    # 例如：0.5 有效，0.0 无效
    results = {"item_id": item_id}
    if size:
        results.update({"size": size})
    return results
```

## 参数顺序问题

### 问题：无默认值的参数在前

不使用 `Annotated` 时：

```python
# ❌ Python 会报错
@app.get("/items/{item_id}")
async def read_items(
    item_id: int = Path(title="The ID of the item to get"),
    q: str  # 无默认值的参数不能在有默认值的参数后面
):
    pass
```

### 解决方案 1：使用 Annotated（推荐）

```python
# ✅ 推荐方式
@app.get("/items/{item_id}")
async def read_items(
    item_id: Annotated[int, Path(title="The ID of the item to get")],
    q: str
):
    pass
```

### 解决方案 2：调整参数顺序

```python
# ✅ 调整顺序
@app.get("/items/{item_id}")
async def read_items(
    q: str,  # 无默认值的放前面
    item_id: int = Path(title="The ID of the item to get")
):
    pass
```

### 解决方案 3：使用 * （kwargs 技巧）

```python
# ✅ 使用 * 让后续参数都成为 keyword arguments
@app.get("/items/{item_id}")
async def read_items(
    *,
    item_id: int = Path(title="The ID of the item to get"),
    q: str
):
    pass
```

---

## 数值验证总结表

| 参数 | 含义 | 数学符号 | 示例 |
|------|------|----------|------|
| `gt` | greater than | > | `gt=0` 表示 > 0 |
| `ge` | greater than or equal | >= | `ge=1` 表示 >= 1 |
| `lt` | less than | < | `lt=100` 表示 < 100 |
| `le` | less than or equal | <= | `le=1000` 表示 <= 1000 |

## 完整示例

### 示例 1：用户 ID 验证

```python
@app.get("/users/{user_id}")
async def read_user(
    user_id: Annotated[int, Path(
        title="User ID",
        description="The unique identifier for the user",
        ge=1,
        le=10000
    )]
):
    return {"user_id": user_id}
```

### 示例 2：分页路径参数

```python
@app.get("/items/{page}")
async def read_items(
    page: Annotated[int, Path(ge=1, le=100, title="Page number")]
):
    return {"page": page, "items": []}
```

### 示例 3：温度验证（浮点数）

```python
@app.get("/weather/{temperature}")
async def get_weather(
    temperature: Annotated[float, Path(
        ge=-273.15,  # 绝对零度
        le=1000,
        title="Temperature in Celsius"
    )]
):
    return {"temperature": temperature}
```

---

## 小结

- 使用 `Path` 为路径参数添加验证和元数据
- 路径参数总是必需的
- 数值验证支持 `gt`, `ge`, `lt`, `le` 四种比较
- 浮点数也支持数值验证
- 推荐使用 `Annotated` 避免参数顺序问题
