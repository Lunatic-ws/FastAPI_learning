# 22 请求文件（Request Files）

## 概念解释

文件上传是Web应用的常见需求，FastAPI提供了强大的文件处理能力。通过 `File()` 和 `UploadFile` 类型，可以轻松处理单文件和多文件上传。

## 核心概念

### 1. File() 函数

用于声明文件参数，从请求中提取文件数据。

```python
from fastapi import FastAPI, File

app = FastAPI()

@app.post("/files/")
async def create_file(file: bytes = File()):
    return {"file_size": len(file)}
```

### 2. UploadFile 类

推荐的文件处理方式，提供了更多功能和更好的性能。

```python
from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile):
    return {"filename": file.filename}
```

### 3. bytes vs UploadFile

- **bytes**：
  - 将整个文件读入内存
  - 适合小文件
  - 返回原始字节数据
  
- **UploadFile**：
  - 使用临时文件存储，不一次性读入内存
  - 适合大文件
  - 提供异步读写方法
  - 包含文件元数据（filename、content_type等）

### 4. UploadFile 属性和方法

```python
from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/file-info/")
async def get_file_info(file: UploadFile = File()):
    content = await file.read()  # 异步读取内容
    await file.seek(0)  # 重置文件指针
    
    return {
        "filename": file.filename,      # 原始文件名
        "content_type": file.content_type,  # MIME类型
        "size": len(content),
        "file": file.file  # Python文件对象
    }
```

### 5. 多文件上传

```python
from fastapi import FastAPI, File, UploadFile
from typing import List

app = FastAPI()

@app.post("/multiple-files/")
async def create_multiple_files(files: List[UploadFile] = File()):
    return {
        "file_count": len(files),
        "filenames": [file.filename for file in files]
    }
```

### 6. 文件与表单字段混合

```python
from fastapi import FastAPI, File, Form, UploadFile

app = FastAPI()

@app.post("/file-with-metadata/")
async def create_file_with_metadata(
    file: UploadFile = File(),
    description: str = Form(),
    tags: str = Form(default="")
):
    content = await file.read()
    return {
        "filename": file.filename,
        "description": description,
        "tags": tags.split(","),
        "size": len(content)
    }
```

## 代码示例

### 示例1：基础文件上传

```python
from fastapi import FastAPI, File, UploadFile
from fastapi.responses import JSONResponse

app = FastAPI()

@app.post("/upload")
async def upload_file(file: UploadFile = File()):
    # 验证文件类型
    if file.content_type not in ["image/jpeg", "image/png", "image/gif"]:
        return JSONResponse(
            status_code=400,
            content={"error": "只支持图片文件"}
        )
    
    # 读取文件内容
    content = await file.read()
    
    return {
        "filename": file.filename,
        "content_type": file.content_type,
        "size": len(content)
    }
```

### 示例2：保存上传文件

```python
from fastapi import FastAPI, File, UploadFile
import os

app = FastAPI()
UPLOAD_DIR = "uploads"

# 确保上传目录存在
os.makedirs(UPLOAD_DIR, exist_ok=True)

@app.post("/save-file")
async def save_file(file: UploadFile = File()):
    file_path = os.path.join(UPLOAD_DIR, file.filename)
    
    # 分块写入文件，适合大文件
    with open(file_path, "wb") as f:
        while True:
            chunk = await file.read(1024 * 1024)  # 1MB chunks
            if not chunk:
                break
            f.write(chunk)
    
    return {
        "filename": file.filename,
        "saved_path": file_path
    }
```

### 示例3：多文件上传与处理

```python
from fastapi import FastAPI, File, UploadFile
from typing import List

app = FastAPI()

@app.post("/upload-images")
async def upload_images(files: List[UploadFile] = File()):
    results = []
    
    for file in files:
        # 只处理图片文件
        if file.content_type and file.content_type.startswith("image/"):
            content = await file.read()
            results.append({
                "filename": file.filename,
                "content_type": file.content_type,
                "size": len(content)
            })
    
    return {
        "total_files": len(files),
        "processed_files": len(results),
        "details": results
    }
```

### 示例4：文件上传进度与验证

```python
from fastapi import FastAPI, File, UploadFile, HTTPException

app = FastAPI()

MAX_FILE_SIZE = 10 * 1024 * 1024  # 10MB
ALLOWED_TYPES = ["image/jpeg", "image/png", "application/pdf"]

@app.post("/upload-validated")
async def upload_validated(file: UploadFile = File()):
    # 验证文件类型
    if file.content_type not in ALLOWED_TYPES:
        raise HTTPException(
            status_code=400,
            detail=f"文件类型不支持: {file.content_type}"
        )
    
    # 验证文件大小
    content = await file.read()
    if len(content) > MAX_FILE_SIZE:
        raise HTTPException(
            status_code=400,
            detail="文件大小超过限制（10MB）"
        )
    
    return {
        "filename": file.filename,
        "size": len(content),
        "status": "uploaded"
    }
```

### 示例5：使用bytes处理小文件

```python
from fastapi import FastAPI, File

app = FastAPI()

@app.post("/upload-small")
async def upload_small_file(file: bytes = File()):
    # bytes适合小文件，一次性读入内存
    return {
        "file_size": len(file),
        "preview": file[:100] if len(file) > 100 else file
    }
```

## 关键要点

1. **UploadFile vs bytes**：
   - 使用 `UploadFile` 处理大文件（推荐）
   - 使用 `bytes` 处理小文件（简单快速）

2. **异步读取文件**：
   ```python
   content = await file.read()  # 正确
   content = file.read()  # 错误，必须await
   ```

3. **UploadFile 常用属性**：
   - `filename`: 原始文件名
   - `content_type`: MIME类型（如 `image/jpeg`）
   - `file`: Python文件对象
   - `read()`: 异步读取文件内容
   - `write()`: 异步写入内容
   - `seek()`: 移动文件指针

4. **HTML文件上传表单**：
   ```html
   <form action="/upload/" method="post" enctype="multipart/form-data">
       <input type="file" name="file">
       <input type="submit">
   </form>
   ```
   **注意**：必须设置 `enctype="multipart/form-data"`

5. **测试文件上传**：
   ```bash
   curl -X POST "http://localhost:8000/uploadfile/" \
        -F "file=@test.txt"
   ```

6. **多文件上传的HTML**：
   ```html
   <input type="file" name="files" multiple>
   ```

7. **文件大小限制**：
   - 读取后检查 `len(content)`
   - 或配置 FastAPI 应用级别的最大请求体大小

8. **安全考虑**：
   - 验证文件类型（不要只依赖扩展名）
   - 限制文件大小
   - 避免使用用户提供的文件名保存文件（可能包含路径遍历攻击）
   - 使用 `uuid` 或安全方法生成存储文件名

9. **OpenAPI文档**：FastAPI自动在Swagger UI中生成文件上传界面

10. **内存管理**：
    - `UploadFile` 使用临时文件，不占用大量内存
    - `bytes` 将整个文件加载到内存中
