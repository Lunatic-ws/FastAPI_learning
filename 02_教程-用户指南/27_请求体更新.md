# 27 请求体更新 (Body - Updates)

## 学习目标

学习如何使用 `PUT` 和 `PATCH` 操作来更新数据，以及如何处理部分更新。

## 使用 PUT 完整更新

使用 HTTP `PUT` 操作来更新项目，会替换现有数据：

```python
from fastapi import FastAPI
from fastapi.encoders import jsonable_encoder
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str | None = None
    description: str | None = None
    price: float | None = None
    tax: float = 10.5
    tags: list[str] = []


items = {
    "foo": {"name": "Foo", "price": 50.2},
    "bar": {"name": "Bar", "description": "The bartenders", "price": 62, "tax": 20.2},
    "baz": {"name": "Baz", "description": None, "price": 50.2, "tax": 10.5, "tags": []},
}


@app.get("/items/{item_id}", response_model=Item)
async def read_item(item_id: str):
    return items[item_id]


@app.put("/items/{item_id}", response_model=Item)
async def update_item(item_id: str, item: Item):
    update_item_encoded = jsonable_encoder(item)
    items[item_id] = update_item_encoded
    return update_item_encoded
```

## PUT 的警告

`PUT` 用于接收应该替换现有数据的数据。

这意味着如果你想使用 `PUT` 更新项目 `bar`，请求体包含：

```json
{
    "name": "Barz",
    "price": 3,
    "description": null
}
```

因为它不包含已存储的属性 `"tax": 20.2`，输入模型将采用默认值 `"tax": 10.5`。

数据将保存为那个"新"的 `tax` 值 `10.5`。

## 使用 PATCH 部分更新

可以使用 HTTP `PATCH` 操作来部分更新数据，只发送想更新的数据，其余保持不变。

**注意**：`PATCH` 不如 `PUT` 常用和知名。许多团队仅使用 `PUT` 进行部分更新。

### 使用 exclude_unset 参数

要接收部分更新，使用 Pydantic 模型的 `.model_dump()` 方法的 `exclude_unset` 参数：

```python
from fastapi import FastAPI
from fastapi.encoders import jsonable_encoder
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str | None = None
    description: str | None = None
    price: float | None = None
    tax: float = 10.5
    tags: list[str] = []


items = {
    "foo": {"name": "Foo", "price": 50.2},
    "bar": {"name": "Bar", "description": "The bartenders", "price": 62, "tax": 20.2},
    "baz": {"name": "Baz", "description": None, "price": 50.2, "tax": 10.5, "tags": []},
}


@app.get("/items/{item_id}", response_model=Item)
async def read_item(item_id: str):
    return items[item_id]


@app.patch("/items/{item_id}")
async def update_item(item_id: str, item: Item) -> Item:
    stored_item_data = items[item_id]
    stored_item_model = Item(**stored_item_data)
    update_data = item.model_dump(exclude_unset=True)
    updated_item = stored_item_model.model_copy(update=update_data)
    items[item_id] = jsonable_encoder(updated_item)
    return updated_item
```

这将生成一个 `dict`，仅包含创建 `item` 模型时设置的数据，排除默认值。

### 使用 update 参数

使用 `.model_copy()` 创建现有模型的副本，并传递包含更新数据的 `update` 参数：

```python
stored_item_model = Item(**stored_item_data)
update_data = item.model_dump(exclude_unset=True)
updated_item = stored_item_model.model_copy(update=update_data)
```

## 部分更新流程总结

要应用部分更新：

1. （可选）使用 `PATCH` 而不是 `PUT`
2. 检索存储的数据
3. 将数据放入 Pydantic 模型
4. 从输入模型生成不含默认值的 `dict`（使用 `exclude_unset`）
5. 创建存储模型的副本，更新其属性（使用 `update` 参数）
6. 将复制的模型转换为可存储在数据库中的内容（使用 `jsonable_encoder`）
7. 将数据保存到数据库
8. 返回更新的模型

## 完整示例

```python
from fastapi import FastAPI, HTTPException
from fastapi.encoders import jsonable_encoder
from pydantic import BaseModel

app = FastAPI()


class Item(BaseModel):
    name: str | None = None
    description: str | None = None
    price: float | None = None
    tax: float = 10.5
    tags: list[str] = []


items = {
    "foo": {"name": "Foo", "price": 50.2},
    "bar": {"name": "Bar", "description": "The bartenders", "price": 62, "tax": 20.2},
}


@app.get("/items/{item_id}", response_model=Item)
async def read_item(item_id: str):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return items[item_id]


@app.put("/items/{item_id}", response_model=Item)
async def replace_item(item_id: str, item: Item):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    
    update_item_encoded = jsonable_encoder(item)
    items[item_id] = update_item_encoded
    return update_item_encoded


@app.patch("/items/{item_id}", response_model=Item)
async def update_item(item_id: str, item: Item):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    
    stored_item_data = items[item_id]
    stored_item_model = Item(**stored_item_data)
    update_data = item.model_dump(exclude_unset=True)
    updated_item = stored_item_model.model_copy(update=update_data)
    items[item_id] = jsonable_encoder(updated_item)
    return updated_item


@app.delete("/items/{item_id}")
async def delete_item(item_id: str):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    
    del items[item_id]
    return {"message": "Item deleted successfully"}
```

## 区分创建和更新模型

为了避免混淆，可以为创建和更新使用不同的模型：

```python
from pydantic import BaseModel


class ItemBase(BaseModel):
    name: str | None = None
    description: str | None = None
    price: float | None = None
    tax: float | None = None


class ItemCreate(ItemBase):
    name: str  # 创建时 name 是必需的
    price: float  # 创建时 price 是必需的


class ItemUpdate(ItemBase):
    pass  # 更新时所有字段都是可选的


class Item(ItemBase):
    tax: float = 10.5  # 存储时的默认值
```

## 核心要点

1. `PUT` 用于完整替换数据
2. `PATCH` 用于部分更新数据
3. 使用 `exclude_unset=True` 排除未设置的字段
4. 使用 `model_copy(update=...)` 更新模型
5. 注意默认值的影响
6. 可以区分创建和更新模型

- 商品信息修改
- 配置项更新
- 部分字段修改
