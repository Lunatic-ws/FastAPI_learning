# 12 额外数据类型

除了常见的基本数据类型（`int`、`float`、`str`、`bool`），FastAPI 还支持更复杂的数据类型，并提供相同的功能：
- 编辑器支持
- 数据转换
- 数据验证
- 自动文档

## 支持的额外数据类型

### UUID
- 标准"通用唯一标识符"
- 在请求和响应中表示为 `str`

### datetime.datetime
- Python 的 datetime 对象
- 在请求和响应中表示为 ISO 8601 格式的 `str`，如：`2008-09-15T15:53:00+05:00`

### datetime.date
- Python 的 date 对象
- 在请求和响应中表示为 ISO 8601 格式的 `str`，如：`2008-09-15`

### datetime.time
- Python 的 time 对象
- 在请求和响应中表示为 ISO 8601 格式的 `str`，如：`14:23:55.003`

### datetime.timedelta
- Python 的 timedelta 对象
- 在请求和响应中表示为 `float`（总秒数）

### frozenset
- 在请求和响应中与 `set` 处理方式相同
- 请求：读取列表，消除重复，转换为 `set`
- 响应：`set` 转换为 `list`

### bytes
- 标准 Python bytes
- 在请求和响应中表示为 `str`（binary 格式）

### Decimal
- 标准 Python Decimal
- 在请求和响应中与 `float` 处理方式相同

## 示例

```python
from datetime import datetime, time, timedelta
from typing import Annotated
from uuid import UUID

from fastapi import Body, FastAPI

app = FastAPI()

@app.put("/items/{item_id}")
async def read_items(
    item_id: UUID,
    start_datetime: Annotated[datetime, Body()],
    end_datetime: Annotated[datetime, Body()],
    process_after: Annotated[timedelta, Body()],
    repeat_at: Annotated[time | None, Body()] = None,
):
    start_process = start_datetime + process_after
    duration = end_datetime - start_process
    return {
        "item_id": item_id,
        "start_datetime": start_datetime,
        "end_datetime": end_datetime,
        "process_after": process_after,
        "repeat_at": repeat_at,
        "start_process": start_process,
        "duration": duration,
    }
```

## 要点

1. 参数在函数内部保持其自然数据类型，可进行常规操作（如日期计算）
2. FastAPI 自动处理数据类型的转换和验证
3. 可查看 [Pydantic 数据类型](https://pydantic.dev/docs/validation/latest/concepts/types/) 了解所有支持的类型
