# 19 响应状态码

## 学习目标

- 理解HTTP状态码分类和含义
- 掌握 `status_code` 参数使用
- 学会使用 `fastapi.status` 便捷常量
- 理解不同场景的状态码选择

## 核心概念

### 1. 设置响应状态码

通过 `status_code` 参数指定：

```python
from fastapi import FastAPI

app = FastAPI()

@app.post("/items/", status_code=201)
async def create_item(name: str):
    return {"name": name}
```

**注意：**
- `status_code` 是**装饰器参数**，不是函数参数
- 可接收数字或 `IntEnum`（如 `http.HTTPStatus`）

### 2. HTTP状态码分类

#### 信息响应 (100-199)
- 很少直接使用
- 不能有响应体

#### 成功响应 (200-299) ⭐
- **200 OK**：默认状态码，成功
- **201 Created**：创建新资源成功
- **204 No Content**：无内容返回（不能有响应体）

#### 重定向 (300-399)
- 可能或不可能有响应体
- **304 Not Modified**：必须有响应体

#### 客户端错误 (400-499) ⭐
- **400 Bad Request**：通用客户端错误
- **404 Not Found**：资源不存在
- **422 Unprocessable Entity**：验证错误（FastAPI自动使用）

#### 服务器错误 (500-599)
- 几乎不直接使用
- 应用出错时自动返回

### 3. 使用便捷常量

```python
from fastapi import FastAPI, status

app = FastAPI()

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(name: str):
    return {"name": name}
```

**常用状态码常量：**
- `status.HTTP_200_OK`
- `status.HTTP_201_CREATED`
- `status.HTTP_204_NO_CONTENT`
- `status.HTTP_400_BAD_REQUEST`
- `status.HTTP_404_NOT_FOUND`
- `status.HTTP_500_INTERNAL_SERVER_ERROR`

### 4. 状态码选择指南

| 操作 | 推荐状态码 | 说明 |
|------|-----------|------|
| GET成功 | 200 | 默认 |
| POST创建 | 201 | 创建新资源 |
| PUT更新 | 200 | 更新成功 |
| DELETE成功 | 204 | 无需返回内容 |
| 资源不存在 | 404 | Not Found |
| 验证失败 | 422 | FastAPI自动 |
| 服务器错误 | 500 | 自动返回 |

### 5. 实际应用示例

```python
from fastapi import FastAPI, status, HTTPException

app = FastAPI()

items = {}

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(item_id: str, name: str):
    if item_id in items:
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST,
            detail="Item already exists"
        )
    items[item_id] = {"name": name}
    return {"id": item_id, "name": name}

@app.delete("/items/{item_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_item(item_id: str):
    if item_id not in items:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Item not found"
        )
    del items[item_id]
    return None  # 204 不应有响应体
```

## 关键要点

- ✅ 默认状态码：200 OK
- ✅ POST创建资源用 201 Created
- ✅ DELETE成功用 204 No Content
- ✅ 使用 `fastapi.status` 常量便于记忆
- ✅ FastAPI自动在OpenAPI文档中记录状态码

## 注意事项

⚠️ 204 和 304 状态码**不能有响应体**
⚠️ `status_code` 是装饰器参数，不是函数参数
⚠️ 客户端错误（400+）通常用 `HTTPException` 抛出
⚠️ 服务器错误（500+）通常由异常自动触发
