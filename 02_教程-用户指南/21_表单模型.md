# 21 表单模型 (Form Models)

## 学习目标

学习如何使用 Pydantic 模型来声明表单字段。

## 前置要求

要使用表单，首先需要安装 `python-multipart`：

```bash
pip install python-multipart
```

**注意**：此功能从 FastAPI 版本 `0.113.0` 开始支持。

## 使用 Pydantic 模型声明表单

你可以使用 Pydantic 模型来声明表单字段，然后将参数声明为 `Form`：

```python
from typing import Annotated
from fastapi import FastAPI, Form
from pydantic import BaseModel

app = FastAPI()


class FormData(BaseModel):
    username: str
    password: str


@app.post("/login/")
async def login(data: Annotated[FormData, Form()]):
    return data
```

FastAPI 会从请求的表单数据中提取每个字段的数据，并提供你定义的 Pydantic 模型。

## 禁止额外的表单字段

在某些特殊用例中，你可能希望将表单字段限制为仅在 Pydantic 模型中声明的字段，并禁止任何额外字段。

**注意**：此功能从 FastAPI 版本 `0.114.0` 开始支持。

你可以使用 Pydantic 的模型配置来 `forbid` 任何 `extra` 字段：

```python
from typing import Annotated
from fastapi import FastAPI, Form
from pydantic import BaseModel

app = FastAPI()


class FormData(BaseModel):
    username: str
    password: str

    model_config = {"extra": "forbid"}


@app.post("/login/")
async def login(data: Annotated[FormData, Form()]):
    return data
```

如果客户端尝试发送额外数据，他们将收到错误响应。

例如，如果客户端尝试发送表单字段：
- `username`: `Rick`
- `password`: `Portal Gun`
- `extra`: `Mr. Poopybutthole`

他们将收到错误响应，告诉他们字段 `extra` 不被允许：

```json
{
    "detail": [
        {
            "type": "extra_forbidden",
            "loc": ["body", "extra"],
            "msg": "Extra inputs are not permitted",
            "input": "Mr. Poopybutthole"
        }
    ]
}
```

## 核心要点

1. 可以使用 Pydantic 模型来声明表单字段
2. 参数需要声明为 `Form()`
3. FastAPI 会自动从表单数据中提取字段并构建模型
4. 可以使用 `model_config = {"extra": "forbid"}` 禁止额外字段
5. 需要 `python-multipart` 依赖

## 实际应用场景

- 用户登录表单
- 用户注册表单
- 数据提交表单
- 需要结构化表单数据的场景
