# 28 依赖注入（Dependencies）

FastAPI拥有强大而直观的**依赖注入**系统。

设计得非常简单易用，让开发者可以轻松集成其他组件。

## 15.1 什么是依赖注入

"依赖注入"意味着代码（路径操作函数）可以声明它需要的东西（依赖），然后系统（FastAPI）负责提供这些依赖。

适用场景：
- 共享逻辑（复用代码）
- 共享数据库连接
- 强制安全、认证、角色要求等
- 减少代码重复

## 15.2 第一步：创建依赖

依赖是一个可以接收路径操作函数所有参数的函数：

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

async def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}

@app.get("/items/")
async def read_items(commons: Annotated[dict, Depends(common_parameters)]):
    return commons

@app.get("/users/")
async def read_users(commons: Annotated[dict, Depends(common_parameters)]):
    return commons
```

`common_parameters`是一个依赖（或"可依赖项"）：
- 可以接收所有路径操作函数的参数
- 可以返回任何内容
- 就像没有装饰器的路径操作函数

## 15.3 使用Depends

在路径操作函数参数中使用`Depends`：

```python
commons: Annotated[dict, Depends(common_parameters)]
```

注意：
- 只给`Depends`一个参数（函数）
- **不要调用它**（不加括号）
- 直接传递函数本身

FastAPI会：
1. 调用依赖函数，传入正确参数
2. 获取结果
3. 将结果赋值给路径操作函数参数

## 15.4 共享Annotated依赖

可以存储`Annotated`值在变量中，在多处使用：

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

async def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}

# 创建类型别名
CommonsDep = Annotated[dict, Depends(common_parameters)]

@app.get("/items/")
async def read_items(commons: CommonsDep):
    return commons

@app.get("/users/")
async def read_users(commons: CommonsDep):
    return commons
```

优点：
- 减少重复
- 保持类型信息
- 编辑器提供自动补全和错误检查

## 15.5 async或非async

依赖函数可以是`async def`或普通`def`：

- `async def`依赖可以在`def`路径操作函数中使用
- `def`依赖可以在`async def`路径操作函数中使用
- FastAPI会正确处理

## 15.6 与OpenAPI集成

依赖的所有参数、验证和需求都会集成到OpenAPI schema中。

交互式文档会显示依赖的所有信息。

## 15.7 依赖注入的优势

- 无需创建特殊类或注册
- 直接传递给`Depends`，FastAPI处理其余工作
- 可用于构建插件和集成
- 支持所有数据库、外部API、认证系统等

## 15.8 层级依赖

可以定义依赖，依赖本身也可以有依赖：

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

def get_db():
    # 数据库连接
    db = "database_connection"
    try:
        yield db
    finally:
        # 关闭连接
        pass

def get_user(db: str = Depends(get_db)):
    # 使用数据库获取用户
    return {"user": "current_user", "db": db}

@app.get("/users/me")
async def read_users_me(user: dict = Depends(get_user)):
    return user
```

形成层级依赖树，FastAPI自动解决所有依赖。

## 小结

- 依赖注入用于声明和复用共享逻辑
- 使用`Depends()`声明依赖
- 依赖函数可以接收所有路径操作参数
- 可以使用`Annotated`创建共享依赖类型
- 支持`async`和普通函数
- 自动集成到OpenAPI文档
- 支持层级依赖
