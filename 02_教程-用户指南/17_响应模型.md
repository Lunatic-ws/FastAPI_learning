# 17 响应模型

## 学习目标

- 理解响应模型的作用和重要性
- 掌握 `response_model` 参数的使用
- 学会使用返回类型注解
- 理解数据过滤机制和安全意义

## 核心概念

### 1. 响应模型基础

通过返回类型注解声明响应模型：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: list[str] = []

@app.post("/items/")
async def create_item(item: Item) -> Item:
    return item

@app.get("/items/")
async def read_items() -> list[Item]:
    return [
        Item(name="Portal Gun", price=42.0),
        Item(name="Plumbus", price=32.0),
    ]
```

**FastAPI会自动：**
- **验证**返回数据
- **生成**JSON Schema
- **序列化**为JSON（Pydantic Rust实现，高性能）
- **过滤**输出数据（安全关键）

### 2. response_model 参数

当返回类型与注解不一致时使用 `response_model`：

```python
from typing import Any
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: list[str] = []

@app.post("/items/", response_model=Item)
async def create_item(item: Item) -> Any:
    return item

@app.get("/items/", response_model=list[Item])
async def read_items() -> Any:
    return [
        {"name": "Portal Gun", "price": 42.0},
        {"name": "Plumbus", "price": 32.0},
    ]
```

**使用场景：**
- 返回字典或数据库对象，但声明为Pydantic模型
- 保持编辑器类型检查正确性（返回类型为 `Any`）

### 3. 安全应用：密码过滤

**错误示范（不要在生产环境使用）：**

```python
from fastapi import FastAPI
from pydantic import BaseModel, EmailStr

app = FastAPI()

class UserIn(BaseModel):
    username: str
    password: str
    email: EmailStr
    full_name: str | None = None

# 危险：返回明文密码
@app.post("/user/")
async def create_user(user: UserIn) -> UserIn:
    return user
```

**正确做法：**

```python
from typing import Any
from fastapi import FastAPI
from pydantic import BaseModel, EmailStr

app = FastAPI()

class UserIn(BaseModel):
    username: str
    password: str
    email: EmailStr
    full_name: str | None = None

class UserOut(BaseModel):
    username: str
    email: EmailStr
    full_name: str | None = None

@app.post("/user/", response_model=UserOut)
async def create_user(user: UserIn) -> Any:
    return user
```

**安全机制：**
- 输入模型包含密码
- 输出模型不包含密码
- FastAPI自动过滤掉password字段

### 4. 继承与类型注解

结合继承获得类型检查支持和数据过滤：

```python
from fastapi import FastAPI
from pydantic import BaseModel, EmailStr

app = FastAPI()

class BaseUser(BaseModel):
    username: str
    email: EmailStr
    full_name: str | None = None

class UserIn(BaseUser):
    password: str

@app.post("/user/")
async def create_user(user: UserIn) -> BaseUser:
    return user
```

**优势：**
- 编辑器/mypy类型检查正确（UserIn是BaseUser子类）
- FastAPI数据过滤正确（只返回BaseUser字段）
- 代码简洁，无需 `response_model` 参数

### 5. 排除未设置字段

使用 `response_model_exclude_unset=True`：

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float = 10.5
    tags: list[str] = []

items = {
    "foo": {"name": "Foo", "price": 50.2},
    "bar": {"name": "Bar", "description": "The bartenders", "price": 62, "tax": 20.2},
}

@app.get("/items/{item_id}", response_model=Item, response_model_exclude_unset=True)
async def read_item(item_id: str):
    return items[item_id]
```

**效果：**
- `foo` 返回：`{"name": "Foo", "price": 50.2}`（省略默认值）
- `bar` 返回：`{"name": "Bar", "description": "The bartenders", "price": 62, "tax": 20.2}`（包含设置值）

**类似参数：**
- `response_model_exclude_defaults=True`
- `response_model_exclude_none=True`

### 6. 包含/排除特定字段

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float = 10.5

@app.get(
    "/items/{item_id}/name",
    response_model=Item,
    response_model_include={"name", "description"},
)
async def read_item_name(item_id: str):
    return items[item_id]

@app.get(
    "/items/{item_id}/public",
    response_model=Item,
    response_model_exclude={"tax"},
)
async def read_item_public_data(item_id: str):
    return items[item_id]
```

## 最佳实践

1. **安全优先**：始终使用输出模型过滤敏感数据
2. **类型注解优先**：优先使用返回类型注解，而非 `response_model`
3. **继承复用**：使用模型继承减少重复代码
4. **性能优化**：对NoSQL数据使用 `exclude_unset` 减少响应体积
5. **文档清晰**：响应模型自动生成文档，保持模型清晰

## 常见问题

**Q: response_model 和返回类型注解的区别？**
A: 优先使用返回类型注解。response_model用于返回类型不一致的情况

**Q: 为什么返回数据被过滤了？**
A: FastAPI会根据响应模型自动过滤未声明的字段，这是安全特性

**Q: 如何返回所有字段包括默认值？**
A: 不使用 `response_model_exclude_unset` 等参数
