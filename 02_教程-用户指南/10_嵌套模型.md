# 10 嵌套模型

FastAPI 支持任意深度的嵌套 Pydantic 模型。

## 列表字段

声明列表类型的字段：

```python
class Item(BaseModel):
    name: str
    tags: list[str] = []  # 字符串列表
```

## 集合类型

使用 `set` 去重：

```python
class Item(BaseModel):
    tags: set[str] = set()  # 自动去重
```

## 嵌套模型

模型属性可以是另一个模型：

```python
from pydantic import BaseModel, HttpUrl

class Image(BaseModel):
    url: HttpUrl
    name: str

class Item(BaseModel):
    name: str
    price: float
    image: Image | None = None  # 嵌套模型
```

请求体示例：
```json
{
    "name": "Foo",
    "price": 42.0,
    "image": {
        "url": "http://example.com/baz.jpg",
        "name": "The Foo"
    }
}
```

## 列表中的嵌套模型

```python
class Item(BaseModel):
    images: list[Image] | None = None  # 模型列表
```

## 深度嵌套

```python
class Offer(BaseModel):
    name: str
    items: list[Item]  # Item 内含 Image 列表
```

## 纯列表请求体

```python
@app.post("/images/")
async def create_images(images: list[Image]):
    return images
```

## 字典类型

```python
@app.post("/weights/")
async def create_weights(weights: dict[int, float]):
    return weights
```

JSON 只支持字符串键，Pydantic 会自动转换。

## 要点

- 支持任意深度嵌套
- `list[Model]`、`set[str]`、`dict[K, V]` 等容器类型
- `HttpUrl` 等特殊类型提供额外验证
- 编辑器支持完备
