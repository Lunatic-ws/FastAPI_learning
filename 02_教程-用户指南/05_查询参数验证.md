# 05 - 查询参数验证 (Query Parameters and String Validations)

## 学习目标

掌握如何使用 `Query` 和 `Annotated` 为查询参数添加额外的验证和元数据。

---

## 核心概念

### 为什么需要验证？

之前的查询参数：
```python
@app.get("/items/")
async def read_items(q: str | None = None):
    # q 是可选的字符串参数
```

**问题**：无法限制参数的长度、格式等。

**解决**：使用 `Query` 添加验证规则。

---

## 使用 Query 进行验证

### 导入必要模块

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()
```

### 添加长度验证

```python
@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(max_length=50)] = None
):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results
```

**说明**：
- `Query(max_length=50)` 限制 q 的最大长度为 50 字符
- 参数仍然是可选的（默认值 `None`）
- FastAPI 会自动验证并返回清晰的错误信息

---

## 常用验证参数

### 1. 字符串长度验证

```python
@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(min_length=3, max_length=50)] = None
):
    # 最小长度 3，最大长度 50
    pass
```

### 2. 正则表达式验证

```python
@app.get("/items/")
async def read_items(
    q: Annotated[
        str | None, 
        Query(pattern="^fixedquery$")
    ] = None
):
    # q 必须完全匹配 "fixedquery"
    pass
```

**正则说明**：
- `^` : 开始位置
- `fixedquery` : 精确匹配这个值
- `$` : 结束位置

### 3. 默认值（非 None）

```python
@app.get("/items/")
async def read_items(
    q: Annotated[str, Query(min_length=3)] = "fixedquery"
):
    # q 默认为 "fixedquery"，不是 None
    pass
```

---

## 必需参数

### 必需参数（无默认值）

```python
@app.get("/items/")
async def read_items(
    q: Annotated[str, Query(min_length=3)]
):
    # q 是必需的，不提供会报错
    pass
```

### 必需但可为 None

```python
@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(min_length=3)]
):
    # q 必需，但可以显式传 None
    pass
```

---

## 列表/多值查询参数

### 接收多个值

```python
@app.get("/items/")
async def read_items(
    q: Annotated[list[str] | None, Query()] = None
):
    query_items = {"q": q}
    return query_items
```

**URL 示例**：
```
http://localhost:8000/items/?q=foo&q=bar
```

**响应**：
```json
{
  "q": ["foo", "bar"]
}
```

### 带默认值的列表

```python
@app.get("/items/")
async def read_items(
    q: Annotated[list[str], Query()] = ["foo", "bar"]
):
    # 默认值是一个列表
    query_items = {"q": q}
    return query_items
```

---

## 元数据声明

### 添加 title 和 description

```python
@app.get("/items/")
async def read_items(
    q: Annotated[
        str | None,
        Query(
            title="Query string",
            description="Query string for the items to search in the database",
            min_length=3
        )
    ] = None
):
    pass
```

这些信息会出现在自动生成的 API 文档中。

---

## 别名 (Alias)

用于处理非 Python 友好的参数名：

```python
@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(alias="item-query")] = None
):
    # URL 使用 item-query，Python 使用 q
    pass
```

**URL 示例**：
```
http://127.0.0.1:8000/items/?item-query=foobar
```

---

## 弃用参数 (Deprecated)

标记参数为已弃用：

```python
@app.get("/items/")
async def read_items(
    q: Annotated[
        str | None,
        Query(
            alias="item-query",
            deprecated=True
        )
    ] = None
):
    # 文档中会显示为弃用状态
    pass
```

---

## 从 OpenAPI 排除

隐藏参数（不在文档中显示）：

```python
@app.get("/items/")
async def read_items(
    hidden_query: Annotated[str | None, Query(include_in_schema=False)] = None
):
    if hidden_query:
        return {"hidden_query": hidden_query}
    else:
        return {"hidden_query": "Not found"}
```

---

## 自定义验证 (AfterValidator)

使用 Pydantic 的 `AfterValidator` 进行复杂验证：

```python
from pydantic import AfterValidator

def check_valid_id(id: str):
    if not id.startswith(("isbn-", "imdb-")):
        raise ValueError('Invalid ID format, must start with "isbn-" or "imdb-"')
    return id

@app.get("/items/")
async def read_items(
    id: Annotated[str | None, AfterValidator(check_valid_id)] = None
):
    # id 必须以 "isbn-" 或 "imdb-" 开头
    pass
```

---

## Query 参数完整列表

### 通用验证和元数据
- `alias`: 参数别名
- `title`: 标题
- `description`: 描述
- `deprecated`: 是否弃用

### 字符串专用验证
- `min_length`: 最小长度
- `max_length`: 最大长度
- `pattern`: 正则表达式

### 其他
- `include_in_schema`: 是否包含在 OpenAPI schema 中

---

## 推荐使用 Annotated

**新写法（推荐）**：
```python
q: Annotated[str | None, Query(max_length=50)] = None
```

**旧写法（不推荐）**：
```python
q: str | None = Query(default=None, max_length=50)
```

**优势**：
1. 默认值更直观（就是函数参数的默认值）
2. 可以在其他地方调用函数（不依赖 FastAPI）
3. 编辑器支持更好

---

## 小结

- 使用 `Query` 为查询参数添加验证和元数据
- 推荐使用 `Annotated` 语法
- 支持字符串长度、正则、列表等多类验证
- 可以添加 title、description、alias、deprecated 等元数据
- 使用 `AfterValidator` 实现自定义验证逻辑
